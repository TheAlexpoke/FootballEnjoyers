# Event illustrations

Eight original, locally authored SVG illustrations for Football Enjoyers. No stock assets, remote images, image-generation APIs, paid services or additional dependencies are used. The go-kart illustration is generic and contains no Nintendo characters or branding. All assets share a 240 × 144 viewBox and the site's navy, gold, white, blue and coral palette.

The Relay Race artwork is a paper airplane with a curved flight trail. It is decorative presentation; the existing individual five-station obstacle-course rules are unchanged.

Files created:

- `beer-pong.svg`
- `pigskin-accuracy-toss.svg`
- `40m-dash.svg`
- `mario-kart-racing.svg`
- `paper-airplane.svg`
- `bottle-flip-frenzy.svg`
- `higher-or-lower.svg`
- `single-week-fantasy.svg`

Each SVG is under 1.5 KB and uses explicit dimensions to reserve its layout space.
